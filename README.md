# LomoType

在手机上打字，文字直接出现在电脑上。

LomoType 让 Android 手机成为电脑的输入前端：手机通过局域网或蓝牙把文字发送到 Windows 电脑，由电脑端程序注入到当前前台窗口，完全绕过电脑本地输入法。文字始终不经任何第三方服务器；唯一的例外是语音输入，音频会上传至你选择的云端识别服务。

## 特性

- **语音输入，解放双手** — 按住说话，识别文字直接上屏
- **调用手机语音输入法** — 手机上已有的输入法即插即用
- **不用麦克风** — 电脑无需额外麦克风设备
- **无需付费** — 免费使用
- **局域网使用，也支持蓝牙连接**
- **多台电脑可同时使用**
- **可以从手机粘贴图片**

## 快速开始

1. **启动电脑端** — 双击 `LomoType.exe`，程序收进系统托盘，无需打开主窗口。
2. **安装手机端** — 电脑设置「手机APP」页扫码下载，或访问 `https://lomotype.com/app/LomoType-1.13.3.apk`。
3. **连接** — 手机与电脑连同一 Wi-Fi，打开 App 点击列表中的电脑；也可先蓝牙配对再连接。
4. **输入配对码** — 首次连接按电脑屏幕提示输入 4 位配对码（若该电脑开启了配对验证）。
5. **打字上屏** — 在输入框打字并发送，文字立即出现在电脑当前窗口。

## 功能详解

### 电脑端

电脑端是常驻系统托盘的小程序：手机连接后，把收到的文字送到电脑当前窗口。

- **托盘运行** — 双击 `LomoType.exe` 启动，最小化到系统托盘（右下角图标区）。右键托盘图标打开菜单：状态（查看/断开连接）、设置、退出。程序单实例运行，可在设置窗口勾选「开机启动」随 Windows 自动运行。
- **设置窗口** — 从托盘菜单「设置」打开。左侧为分类页签，所有修改即时生效、自动保存，无需点确定：常规、快捷键、后缀、配对、手机APP、关于。
- **输入方式** — 决定文字以何种方式进入电脑当前窗口（设置 → 常规 → 输入方式）：
  - **模拟按键**（默认）：模拟键盘输入，绕过电脑输入法，绝大多数场景用此方式。
  - **剪贴板粘贴**：写入剪贴板并按下 `Ctrl + V`。部分应用拦截模拟按键（游戏、远程桌面）时改用此方式。
- **快捷键**（默认 `Ctrl + Win`）：用于在电脑上遥控手机。按住向手机发送触摸按下，屏幕底部出现胶囊窗口实时同步输入内容；松开发送触摸抬起。语音模式下按住开始录音、松开发送识别文字——无需碰手机即可语音输入。可在 设置 → 快捷键 录制自定义组合（至少一个修饰键；也可单独使用鼠标侧键 X1 / X2）。
- **输入后缀** — 每条文字送达后自动补按一个按键，模拟扫描枪式输入（如仓库、收银场景）。可选：不使用后缀、回车 Enter、发送 Ctrl+Enter、制表符 Tab、软回车 Shift+Enter、方向键 ↑ ↓ ← →，并可设置按键前的延迟（毫秒）。
- **配对码** — 首次连接时电脑屏幕弹出 4 位数字，在手机输入即可；配对成功后该手机被记住，以后连接无需再输。可在 设置 → 配对 关闭验证或管理（移除 / 全部清除）已配对手机。
- **自动调暗手机屏幕** — 勾选后连接时把手机屏幕亮度调到最低；取消勾选或断开连接后恢复系统亮度。
- **传输方式（局域网 / 蓝牙）** — 电脑端同时运行两种传输方式。局域网需手机与电脑在同一 Wi-Fi；蓝牙无需局域网，需先在手机和电脑的系统设置中完成蓝牙配对。设置窗口左下角的状态指示显示运行状态与当前连接所用方式。
- **发送图片** — 手机「文件」页选图后发送，图片经局域网传到电脑，通过剪贴板粘贴到当前窗口（与「输入方式」设置无关，始终使用粘贴；图片传输仅支持局域网）。
- **Windows 管理员权限** — 普通窗口中所有功能正常使用；若需在管理员权限窗口（任务管理器、管理员终端）中上屏，运行安装包即可。

### 手机端

手机端负责打字与发送，配合电脑端实现「手机打字、电脑上屏」。

- **发现与连接** — 打开 App，顶部「可用服务」列表自动显示发现的电脑：局域网（同一 Wi-Fi 的电脑自动出现）与蓝牙（已完成系统配对的电脑出现，需在设置中开启蓝牙发现）。点击条目连接，长按开启/关闭「自动连接」。
- **首次配对** — 连接开启配对码验证的电脑时弹出 4 位数字输入框，输入电脑屏幕上的配对码即可；30 秒无操作自动取消。
- **键盘输入** — 在输入框打字，点右下角发送按钮或键盘「完成」键发送。发送后输入框自动清空，支持多行与粘贴多行文本。
- **历史记录** — 「历史」页保存最近发送或清空的文本（默认 20 条）：点击回填（不自动发送），长按删除单条，可一键清空。
- **文件与图片** — 底部「文件」页内置相册（需授予存储权限）：点图片选择（进入文件模式）或取消，点放大图标全屏预览。文件模式下输入框只读并显示缩略图，可删除或发送；图片预览支持翻页、缩放、直接发送；长按图片弹出快捷菜单。图片传输仅支持局域网。
- **语音输入** — 点麦克风进入语音模式（需先配置识别服务）：按住「按住说话」录音，松开发送，上滑取消；键盘模式下长按麦克风（约 0.4 秒）触发快捷语音。详见下文「语音输入」。
- **无障碍服务** — 键盘模式下需开启无障碍服务，电脑热键才能向手机发送触摸指令（语音模式不需要）。未开启时状态栏显示橙色小人图标，点击跳转系统设置。
- **抢占连接** — 一台电脑同一时间只能被一台手机占用；另一台手机连接时旧连接自动断开（提示「已切换」），新手机接管。同一台手机换传输方式再次连接时会被识别为同一设备而静默接管。
- **多台电脑** — 一台手机可同时连接多台电脑，列表按顺序排列，第一台已连接的为「活跃电脑」，所有文字、图片、语音都发送给它；可拖动排序（保存到下次启动），「活跃电脑」断开后下一台自动接任。
- **主题与语言等设置** — 主题（跟随系统 / 亮色 / 深色）、语言（简体中文 / 繁体中文 / English / 跟随系统）、局域网 / 蓝牙发现开关等。
- **应用更新** — App 启动时自动检查新版本，设置页可手动检查；发现新版本后可一键下载安装（下载前校验文件完整性）。

### 语音输入

语音输入让你「按住说话」，把识别文字直接送到电脑。

- **语音模式** — 点麦克风进入：键盘隐藏、输入框只读，底部出现「按住说话」按钮。按住开始录音（实时显示识别中的文字），松开发送，上滑取消；点按钮右侧键盘按钮切回键盘输入。
- **快捷语音** — 键盘模式下长按麦克风（约 0.4 秒）开始：切到语音输入、录音、松开发送后自动回到键盘模式，未发送的键盘文字自动恢复。
- **语音识别配置** — 设置 → 语音识别 管理识别服务，凭据加密存储在手机本地、不上传。同一时间只能启用一个，新增或修改后点「保存并启用」自动启用并切换到语音模式。
- **支持的识别服务** — 火山引擎豆包（默认）、阿里云实时语音识别（可选 Qwen3-ASR / Fun-ASR 模型）、讯飞（以上按住时实时显示结果）；智谱 GLM-ASR（单次最长 30 秒）、OpenAI Whisper、Groq Whisper、本地 / 自定义 Whisper（以上录音结束后返回结果）。
- **在电脑端填写** — 连接电脑时配置表单出现「在电脑端填写」按钮：电脑弹出填写窗口，填好后点「发送到手机」自动回填手机表单（回填不等于保存，仍需在手机上点「保存并启用」）。
- **识别文字处理** — 控制识别结果在发送前自动处理：中文数字转阿拉伯数字、日期/货币格式化、标点处理、标点转换（中文 ↔ 英文）、数字英文前后加空格、首字母自动大写。
- **收音增强** — 自动放大轻声说话音量，静音时不放大环境噪音。
- **截图设置坐标** — 电脑热键在键盘模式下的录音依赖「截图设置坐标」标记的录音键位置（通常为空格键），自动适配屏幕旋转与分辨率变化。
- **支持的输入法** — 按住录音：豆包、微信 / WeType、百度、搜狗、讯飞、QQ 拼音；点击录音：Typeless、Gboard。其他输入法暂不支持。

## 常见问题

- **列表里找不到电脑？** 确认手机与电脑在同一 Wi-Fi、电脑端托盘程序正在运行、Windows 防火墙未拦截；或改用蓝牙连接（先完成系统蓝牙配对）。
- **输入的文本没有上屏？** 部分应用（游戏、远程桌面）会拦截模拟按键。请在电脑设置「常规」页把输入方式切换为「剪贴板粘贴」。
- **语音输入不工作？** 确认已启用识别配置、已授予麦克风权限、网络正常。
- **一台手机可以连接多台电脑吗？** 可以。手机同时列出多台电脑并分别保持连接；同一台电脑同一时间只能被一台手机占用。列表第一台为「活跃电脑」，所有文字、图片、语音发送给它。
- **手机能发图片到电脑吗？** 可以。手机「文件」页选择图片后发送，图片经局域网直接传到电脑并粘贴到当前窗口（仅支持局域网）。
- **输入的文字安全吗？** 文字经局域网或蓝牙直接从手机送到电脑，不经过第三方服务器；唯一例外是语音输入，音频会上传至你选择的云端识别服务。
