找不到电脑端？

通常是网络、防火墙或蓝牙配对问题，按以下顺序逐一排查。

先检查这些

多数情况能在这一步解决：

  • 电脑端程序正在运行 -- 系统托盘能看到 LomoType 图标；没有就双击 LomoType.exe 启动。
  • 手机与电脑连同一 Wi-Fi -- 连了访客网络或不同路由器则发现不到。
  • 蓝牙需先配对 -- 在手机和电脑的系统蓝牙设置中完成配对后才会出现。
  • 手机端发现开关已开启 -- 设置中的「局域网」「蓝牙」开关默认开启，确认未被关闭。

网络环境问题

  • 企业 / 校园网络 -- 常禁止设备互访。改用手机热点让电脑连接，或改用蓝牙。
  • Wi-Fi AP 隔离 / 访客网络 -- 路由器开启后同 Wi-Fi 设备也无法互访。在路由器后台关闭该选项，或换普通家用 Wi-Fi。
  • VPN / 代理 -- 可能使两者不在同一网段。关闭后重试。
  • 多块网卡 / 虚拟网卡 -- 暂时禁用多余网卡（虚拟机、虚拟网卡等），或改用蓝牙。

快速验证：手机开热点让电脑连，再连同一热点打开 App 看列表是否出现电脑。

Windows 防火墙拦截

首次运行通常会弹出授权窗口，若点了「取消」或被静默拦截，手机便连不进来。

  • 检查放行规则 -- 打开「Windows Defender 防火墙」->「允许应用通过防火墙」，找到 LomoType 并勾选「专用」网络；列表中没有则手动为 LomoType.exe 添加入站规则。
  • 临时关闭防火墙验证 -- 短暂关闭后重试，若能发现即确认是防火墙问题，再配置规则并重新开启。

第三方安全软件（杀毒、安全卫士等）也可能拦截，排查时可临时退出测试。

改用蓝牙连接

蓝牙不依赖局域网，不在同一 Wi-Fi 时也能用。前提是先完成系统蓝牙配对：

  1. 电脑系统蓝牙设置中开启蓝牙，添加并配对手机。

  2. 手机系统蓝牙设置中完成与电脑的配对（双向确认）。

  3. 确认电脑端托盘程序运行、蓝牙已开启。

  4. 手机端设置中开启「蓝牙」发现，列表即会出现已配对的电脑。

系统配对是前提，App 内无需再配对。详见 常见问题 · 蓝牙连接。

协议版本不兼容

列表中出现了电脑但带警告图标、无法连接，说明两端协议版本不匹配。把手机 App 与电脑程序都更新到最新版本后重试。

  • 手机端：设置页手动检查更新
  • 电脑端：设置 -> 关于 检查更新

列表完全空白是「未发现」（见上文）；有电脑但带警告图标是「协议不兼容」（本节）。

仍然找不到？

  • 重启两端 -- 退出电脑端托盘程序后重启；手机端彻底杀掉 App 再打开。
  • 确认电脑端版本足够新 -- 旧版可能不支持当前手机端协议，更新到最新版。
  • 改用蓝牙 -- 局域网环境受限时蓝牙是最稳妥的替代方案。
  • 查看日志 / 端口 -- 设置 -> 关于 连续三次点击图标开启「开发模式」；若曾在开发模式中改过 TCP 端口，需重启电脑端程序才生效。日志目录可在开发模式页一键打开。
