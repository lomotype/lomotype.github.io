手机端使用

手机端负责打字与发送，配合电脑端实现「手机打字、电脑上屏」。

安装下载

电脑设置窗口「手机APP」页扫码下载，或访问 lomotype.com/lomotype_latest.apk

Android 13 及以上：侧载安装的 App 需先在系统设置 -> 应用 -> LomoType ->「允许受限设置」中放开限制，否则无法开启无障碍服务。

发现与连接

打开 App，顶部「可用服务」列表自动显示发现的电脑：

  • 局域网 -- 同一 Wi-Fi 的电脑自动出现
  • 蓝牙 -- 已完成系统蓝牙配对的电脑出现（需在设置中开启蓝牙发现）

点击条目连接，再次点击断开；长按开启/关闭「自动连接」（启动 App 后自动连上）；锁图标表示该电脑开启了配对码验证。顶部状态栏显示连接状态与已连接电脑的主机名。

「自动连接PC端」是总开关（设置 -> 其他，默认开启）：关闭后不再把新成为「活跃电脑」的条目自动加入自动连接，已加入的条目不受影响。长按单台电脑则是单独开关它的自动连接。

首次配对

连接开启配对码验证的电脑时弹出 4 位数字输入框，输入电脑屏幕上的配对码即可。输错可重试，30 秒无操作自动取消。

键盘输入

在输入框打字，点右下角发送按钮或键盘「完成」键发送。发送后输入框自动清空，文字出现在电脑当前窗口。

  • 左下角垃圾桶按钮清空输入框
  • 支持多行，发送内容保留换行，可直接粘贴多行文本

历史记录

「历史」页保存最近发送或清空的文本（默认 20 条）：点击回填到输入框（不自动发送），长按删除单条，可一键清空。

文件与图片

底部「文件」页内置相册（需授予存储权限），点图片即可选择（进入文件模式）或取消，点右下角放大图标全屏预览。

  • 文件模式 -- 选择图片后输入框变为只读并显示缩略图，可删除或发送；发送后图片传到电脑并粘贴到当前窗口
  • 图片预览 -- 左右滑动翻页、捏合缩放，右上角按钮选择/取消，底部绿色按钮直接发送当前图片
  • 长按图片 -- 弹出快捷菜单，可直接预览或发送

图片传输仅支持局域网，蓝牙连接时不可用。

语音输入

点输入框右下角麦克风进入语音模式（需先配置识别服务）：按住「按住说话」录音，松开发送，上滑取消。键盘模式下长按麦克风（约 0.4 秒）触发快捷语音，发送后自动回键盘模式。详见语音输入。

无障碍服务

键盘模式下需开启无障碍服务，电脑热键才能向手机发送触摸指令。路径：系统设置 -> 无障碍 -> LomoType -> 开启。

未开启时状态栏显示橙色小人图标，点击可跳转到系统无障碍设置。

语音模式下不需要此服务。

抢占连接

一台电脑同一时间只能被一台手机占用。另一台手机连接时旧连接自动断开（手机提示「已切换」），新手机接管，且不会自动重连。

同一台手机换传输方式（如局域网切蓝牙）再次连接时，会被识别为同一设备而静默接管。

多台电脑

一台手机可同时连接多台电脑。列表按顺序排列，第一台已连接的电脑为「活跃电脑」，其余已连接的为候选：所有文字、图片、语音都发送给「活跃电脑」。

  • 拖动条目右侧手柄可调整顺序，顺序会保存到下次启动
  • 「活跃电脑」断开后，列表中下一台已连接的电脑自动接任
  • 成为「活跃电脑」会自动开启该电脑的「自动连接」（可长按关闭）

主题与语言等设置

  • 主题 -- 跟随系统 / 亮色 / 深色
  • 语言 -- 简体中文 / 繁体中文 / English / 跟随系统
  • 局域网 / 蓝牙发现开关 -- 控制对应发现机制是否运行
  • 显示日志 -- 控制「日志」页签是否显示

应用更新

  • App 启动时自动检查新版本；设置页可手动检查
  • 发现新版本后可一键下载安装，下载可取消，安装前校验文件完整性
  • 下载完成自动调起系统安装界面；部分设备需先在系统设置中允许「安装未知应用」
