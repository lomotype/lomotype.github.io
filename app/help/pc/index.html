电脑端使用

电脑端是常驻系统托盘的小程序：手机连接后，把收到的文字送到电脑当前窗口。

运行程序

双击 LomoType.exe 启动，程序最小化到系统托盘（右下角图标区），不弹主窗口。右键托盘图标打开菜单：状态（查看/断开连接）、设置、退出。

程序单实例运行。在设置窗口勾选「开机启动」后随 Windows 自动运行。

设置窗口

从托盘菜单「设置」打开（单击托盘图标也可）。左侧为分类页签，所有修改即时生效、自动保存，无需点确定。

常规

输入方式、开机启动、自动调暗手机屏幕

快捷键

录制电脑热键（默认 Ctrl + Win）

后缀

每条文字送达后自动按下的按键与延迟

配对

配对码开关、已配对手机管理

手机APP

手机端下载二维码

关于

版本号、检查更新；连续三次点击图标可开启隐藏的「开发模式」查看日志与端口

输入方式

决定文字以何种方式进入电脑当前窗口（设置 -> 常规 -> 输入方式）：

  • 模拟按键（默认）-- 模拟键盘输入，绕过电脑输入法。绝大多数场景用此方式。
  • 剪贴板粘贴 -- 写入剪贴板并按 Ctrl + V。部分应用拦截模拟按键（游戏、远程桌面）时改用此方式。

快捷键 Ctrl + Win

快捷键用于在电脑上遥控手机：

  • 按住 向手机发送触摸按下，屏幕底部出现胶囊窗口实时同步手机输入内容
  • 松开 发送触摸抬起
  • 语音模式下：按住开始录音，松开发送识别文字 -- 无需碰手机即可语音输入

默认 Ctrl + Win。设置 -> 快捷键 点击输入框后直接按下想用的组合即可录制（至少包含一个修饰键；也可单独使用鼠标侧键 X1 / X2）。

键盘模式下，电脑热键需配合手机端无障碍服务与「截图设置坐标」才能触发录音，详见语音输入 · 截图设置坐标。

输入后缀

每条文字送达后可让电脑自动补按一个按键，模拟扫描枪式输入（如仓库、收银场景）。设置位置：设置窗口 -> 后缀。

  • 不使用后缀（默认）
  • 回车 Enter / 发送 Ctrl+Enter / 制表符 Tab / 软回车 Shift+Enter
  • 方向键 ↑ ↓ ← ->

可设置按键前的延迟（毫秒）。

配对码

首次连接时电脑屏幕弹出 4 位数字配对码，在手机输入即可。配对成功后该手机被记住，以后连接无需再输。

可在设置 -> 配对 关闭配对码验证，或管理（移除 / 全部清除）已配对手机。

自动调暗手机屏幕

勾选后连接时把手机屏幕亮度调到最低，让手机放在桌上不发光干扰：

  • 勾选时已有手机连接，立即生效
  • 未连接时在下一次连接的首条文字上屏后生效
  • 取消勾选或断开连接后恢复系统亮度

传输方式（局域网 / 蓝牙）

电脑端同时运行两种传输方式：

局域网

手机与电脑需在同一 Wi-Fi 或路由器下。

蓝牙

无需局域网，需先在手机和电脑的系统设置中完成蓝牙配对。

设置窗口左下角的状态指示显示运行状态，绿色勾标记当前连接所用方式；点击查看详情（设备名、传输类型、连接时长等）并断开。蓝牙步骤见常见问题 · 蓝牙连接。

发送图片

手机在「文件」页选择图片后：

  • 屏幕底部胶囊 -- 显示图片缩略图与文件名、尺寸等信息
  • 发送 -- 手机点发送后，图片经局域网传到电脑，通过剪贴板粘贴到当前窗口（与「输入方式」设置无关，始终使用粘贴）

图片传输仅支持局域网，蓝牙连接时不可用。

Windows 管理员权限

普通窗口中所有功能正常使用。若需在管理员权限窗口（任务管理器、管理员终端）中上屏，运行 LomoType-Setup-<版本号>.exe 安装包即可。服务只在向管理员窗口输入时才发挥作用，不安装也不影响日常使用。
