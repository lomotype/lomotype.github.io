常见问题

常见问题快速排查。

连接与发现

列表里找不到电脑？

确认手机与电脑在同一 Wi-Fi、电脑端托盘程序正在运行、Windows 防火墙未拦截。详见完整排查。

想用蓝牙连接需要先做什么？

电脑与手机系统蓝牙设置中完成配对，确认托盘程序运行、蓝牙已开启，手机端设置中开启蓝牙发现。详见步骤。

蓝牙不依赖局域网，不在同一 Wi-Fi 时也可使用。

连接经常断开？
  • 手机切后台会自动断开，回前台后自动重连
  • 网络波动时每秒自动重试
  • 同一手机经局域网和蓝牙同时连同一电脑时，新传输自动接管旧的
配对码总是错误？

以电脑屏幕当前显示的 4 位为准；超过 30 秒未输入自动取消，重新连接即可。

快捷键与录音

Ctrl + Win 没反应？
  • 语音模式：确认处于语音模式且已启用识别配置
  • 键盘模式：确认无障碍服务已开启、已完成截图设置坐标
  • 确认组合键未被其他程序占用
Ctrl + Win 录音位置不对？

重新截图设置坐标标记空格键位置；确认当前输入法为支持的输入法（豆包、微信、搜狗、百度、讯飞、QQ 拼音按住录音；Typeless、Gboard 点击录音）。

文字上屏

输入的文本没有上屏？

部分应用拦截模拟按键（游戏、远程桌面）。在设置 -> 常规 -> 输入方式 切换为「剪贴板粘贴」。

语音输入

语音输入不工作？
  • 确认已启用识别配置（设置 -> 语音识别）
  • 确认已授予麦克风权限
  • 语音识别依赖云端服务，需保持网络连接
  • 部分服务需特定 endpoint / 模型配置，参考语音识别配置

其它问题

一台手机可以连接多台电脑吗？

可以。手机同时列出多台电脑，可分别保持连接。同一台电脑同一时间只能被一台手机占用，新连接会抢占旧连接。连接多台电脑时，列表第一台为「活跃电脑」，所有文字、图片、语音发送给它，可拖动排序调整。

手机能发图片到电脑吗？

可以。手机「文件」页选择图片后发送，图片经局域网直接传到电脑并粘贴到当前窗口（图片传输仅支持局域网，不支持蓝牙）。

输入的文字会经过哪里？安全吗？

文字经局域网或蓝牙直接从手机送到电脑，不经过第三方服务器。唯一例外是语音输入 -- 音频会上传至你选择的云端识别服务。

支持哪些系统版本？
  • 手机端：Android 7.0（API 24）及以上
  • 电脑端：Windows 7 SP1 及以上（建议 Windows 10 / 11）
